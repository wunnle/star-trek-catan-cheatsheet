# Star Trek Catan cheat sheet

An English reference for the German edition of Star Trek Catan (Kosmos), so non-German players can read the crew (support) cards and development cards.

`index.html` is the whole sheet, live at https://startrek.kafagoz.com. It also prints on two A4 pages: in the print dialog, turn on background graphics.

`star-trek-catan-cheatsheet.pdf` is the same sheet as a ready-to-print PDF.

Fan-made reference. Not affiliated with Kosmos, Catan GmbH or CBS Studios.
